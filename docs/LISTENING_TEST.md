# 日本語ブラインド試聴手順

## 目的

`natural.wav`が`pitch-only.wav`より自然に聞こえるかを、音量差やファイル名の先入観を避けて判定します。これは公開プリリースより前に完了する人手ゲートです。

## サンプル

本人の同意と利用権限があるローカル音声だけを使います。最低3人の話者について、同じマイク距離・ゲインで次を含む48 kHz mono WAVを用意します。

- 通常の短文
- サ行（例: 「新作ソフトを試す」）
- 破裂音（例: 「パッとボタンを押す」）
- 小声
- 笑い声

音声をこのリポジトリへcommitしないでください。

## 生成

各サンプルを公開ベータ版UIと同じPitch `+3.0`、Formant `+2.0`で処理します。話者ごとの調整は行わず、同じ入力をPitch-onlyとNaturalで比較します。実行ごとの`metrics.json`はローカル評価フォルダに保存し、リポジトリへcommitしません。

## 匿名化と提示順

評価を行わない担当者が、`pitch-only.wav`と`natural.wav`をランダムに`A.wav`、`B.wav`へコピーします。半数の設問では対応を逆にし、評価者へ対応表を見せません。Dryは基準確認に使えますが、A/B選択の直前に音量を変更しないでください。

## 評価票

各発話について次を記録します。

1. AとBのどちらが自然か（A / B / 同等）
2. ロボット感・金属音が少ない方
3. サ行・破裂音が崩れない方
4. 会話で使いたい方
5. 目立った問題の自由記述

最低3人の評価者、話者ごとに5種類以上の発話を推奨します。自分自身の声だけで判定しません。

## Go / No-Go

- **Go:** NaturalがPitch-onlyより自然だという票が、同等票を除いた有効票の過半数。重大な金属音や子音崩れが反復していない。
- **No-Go:** 過半数に届かない、または小声・笑い声・サ行で再現性のある劣化がある。

No-Goの場合は公開配布へ進まず、フォルマント推定、処理順、Signalsmith設定を見直します。結果は`docs/LISTENING_RESULTS.md`などの集計だけを保存し、原音は保存しません。
