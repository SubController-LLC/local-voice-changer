# Windows実機QAチェックリスト

この項目はGitHub CIでは再現できず、現在の公開ベータでは未完了です。安定版の前に全項目を完了します。ベータ利用者から結果を受け取る場合も、実施日、Windows版、マイク種別、VB-CABLE版、合否だけを記録し、音声ファイル、氏名、デバイス固有IDは保存しません。

## 安定版向け必須ゲート

- [ ] Windows 10 x64で物理マイクからCABLE Inputへ送り、CABLE Outputで受信できる。
- [ ] Windows 11 x64で同じ経路を確認できる。
- [ ] 通話アプリのループバックで送受信できる。
- [ ] 利用するゲームのボイスチャットで`CABLE Output`を入力に選び、送受信できる。
- [ ] Stop、Bypass、Muteに危険なクリックや継続ノイズがない。
- [ ] デバイス切断時に安全停止し、再読み込み案内が表示される。
- [ ] デバイスの排他利用、スリープ復帰、既定デバイス変更から復旧できる。
- [ ] 60分試験で回復不能な音切れ、クロックずれ、キュー発散がない。
- [ ] マイクからCABLE Outputまでの遅延p95が120 ms以下。150 ms以上はNo-Go。
- [ ] ゲームと配信を同時に動かした状態でも10 ms DSP期限を継続して守る。
- [ ] SmartScreen警告とSHA-256確認を含め、非技術者が手順だけで起動できる。
- [ ] 5人中4人以上の非技術者が、ライブの手助けなしで10分以内に通話ループバックへ到達できる。

VB-CABLEは公式配布元から利用者が導入し、アプリへ同梱・自動インストールしません。
